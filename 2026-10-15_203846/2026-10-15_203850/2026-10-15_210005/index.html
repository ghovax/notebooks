Link 0 commands

The Link 0 commands set the job’s memory, processors and files before the route; each is explained after the Gaussian manual.

Command Value Meaning
%OldChk Checkpoint file copied into this job’s checkpoint at the start, to read data from a previous calculation.
%Chk Checkpoint file this job writes.
%Mem 512 MB Dynamic memory available to Gaussian.
%NProcShared 1 Number of processors used in shared-memory parallel execution.

Route keywords and options

The route selects the method, basis set and job type. Each keyword is listed with its meaning, followed by its options, as Gaussian read them.

Keyword

Meaning

Options

Option

Value

Meaning

PM6

PM6 semi-empirical method.

IRC

Reaction path following along the intrinsic reaction coordinate from a transition structure.

RCFC

Read the Cartesian force constants from the checkpoint file.

MaxPoints

100

At most 100 points along the path in each direction.

StepSize

10

Step of 10\times 0.01\,a_0 along the path.

Phase

3, 21

Forward motion along the transition vector increases the internal coordinate defined by atoms 3, 21.

SCF

Controls of the self-consistent field procedure.

Tight

Tight SCF convergence, the default.

MaxCycle

128

At most 128 SCF cycles.

Geom

Source and handling of the molecule specification.

AllCheck

Take the geometry, charge, multiplicity and title from the checkpoint file.

Guess

Initial guess for the SCF wavefunction.

Read

Read the initial guess from the checkpoint file.

NoSymm

Keep the input orientation and do not use molecular symmetry.
